# Kintetsu-Railway-CRT-panel-simulator
As title, old CRT info screens show nostalgic vibe, so I decided to simulate it using Python.
# Usage
Install Pygame, run main.py, script should make a fullscreen window, press any key to generate a random display info, use escape to exit. Tested only on Windows OS.
